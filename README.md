# เว็บไซต์ป่างิ้วและระบบหลังบ้าน

เจ้าของ GitHub: pangewdole-cloud / pangiew-learning-center

เว็บไซต์ต้นฉบับอยู่ใน site/; ข้อความและรูปที่แก้ผ่านหลังบ้านอยู่ใน content/.
ระบบรักษา HTML เดิมเมื่อยังไม่ได้แก้ข้อความ ไม่ต้องแก้โค้ดเพื่อแก้ข้อมูลทั่วไป.
ห้องสมุดดิจิทัล มุมหนังสือชุมชน และ ETV มีเมนูแก้รายการแยกกันในหลังบ้าน.

## ใช้งานประจำ
เปิด URL เว็บไซต์จริงตามด้วย /admin/ แล้วเข้าสู่ GitHub เจ้าของบัญชี.
เลือกหน้าหรือคลังสื่อ แก้ไขและกดเผยแพร่; รอ Vercel สร้างเว็บจน Ready.
ก่อนเพิ่มหนังสือหรือลิงก์ ตรวจสิทธิ์การเข้าถึงและต้นทางด้วยตนเอง.
ระบบนี้ไม่เพิ่มฐานข้อมูลผู้เรียน และไม่เปลี่ยนการเชื่อม Apps Script เดิม.

## ติดตั้งครั้งแรก
1. อัปโหลด admin, api, content, lib, scripts, site, package.json และ vercel.json ไปยังรากคลัง GitHub.
2. นำเข้าคลังนี้ใน Vercel บัญชีของเจ้าของ เลือก Other และ Root Directory ./.
3. สร้าง GitHub OAuth App ของเจ้าของ ใช้ Homepage เป็นโดเมนจริง และ Redirect URI เป็นโดเมนจริงตามด้วย /api/cms-callback.
4. เพิ่มตัวแปร Production: CMS_ORIGIN (HTTPS origin ไม่มี / ท้าย), CMS_GITHUB_REPO (pangewdole-cloud/pangiew-learning-center), GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET และ CMS_SESSION_SECRET (สุ่มอย่างปลอดภัยอย่างน้อย 32 ตัวอักษร).
5. เก็บความลับใน Vercel เท่านั้น อย่าอัปโหลด .env หรือไฟล์รหัสลับลง GitHub. Redeploy แล้วทดสอบเข้าสู่ระบบ บันทึก และตรวจหน้าเว็บจริง.
6. OAuth ใช้สิทธิ์ public_repo ซึ่งกว้างถึงคลังสาธารณะอื่นที่บัญชีเข้าถึงได้ ผู้ดูแลต้องอ่านขอบเขตก่อนยินยอม. โค้ด callback รับเฉพาะ pangewdole-cloud.

## สำรองและย้ายผู้ดูแล
ทุกเดือนและก่อนเปลี่ยนระบบ: GitHub → Code → Download ZIP แล้วเก็บสำรองบนเครื่องและสื่ออีกแห่ง.
GitHub เก็บประวัติการแก้ข้อมูลไว้ ใช้ revert เพื่อย้อนการแก้ไข และรอ Vercel deploy ใหม่.
โฟลเดอร์ dist/ หลังสั่ง npm run build เป็นเว็บ HTML พร้อมย้ายไปผู้ให้บริการอื่น; หลังบ้าน OAuth ต้องใช้โฮสต์ที่รัน Node API ได้.
อย่าลบบัญชีเก่าหรือย้ายโดเมนจนกว่าจะตรวจสำเนาใหม่ครบ. เปลี่ยนอีเมลกู้คืนบัญชีให้เป็นปัจจุบัน.
การเพิ่มผู้ดูแลต้องปรับ allowlist, สิทธิ์ GitHub และเงื่อนไข Vercel ที่ใช้ในขณะนั้น.

## ข้อจำกัด
การแก้ข้อความ/รูปในหน้าเดิมไม่เพิ่มหรือลบโครงสร้างเมนูโดยอัตโนมัติ. เปลี่ยนโครงสร้าง HTML ใน site/ ต้องสร้าง manifest ใหม่.
ชื่อ “ชื่อรายการในหลังบ้าน” ใช้จัดรายการเท่านั้น ส่วนหัวข้อบนหน้าเว็บแก้ในรายการข้อความ.
ระบบเก็บข้อมูลเผยแพร่สาธารณะเท่านั้น ไม่ใช้เก็บคะแนนหรือข้อมูลส่วนบุคคลผู้เรียน.
แผนฟรีและโควตาอาจเปลี่ยน ต้องตรวจเงื่อนไขบริการเป็นระยะ.
ชุดนี้ผ่านการทดสอบในเครื่อง การยืนยันการบันทึกจริงต้องทำหลังเชื่อมบัญชี.
